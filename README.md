## The idea behind a sheet you summon

Ergonis Software built this around one observation: the information is already in the software, it is simply
buried one menu at a time. Rather than maintaining a reference document that goes stale, the utility
interrogates the menus of the frontmost program at the instant you ask, then draws the result as a single
table arranged the way those menus are arranged. Nothing is written in advance, so an application updated
this morning is described correctly this afternoon, and software released long after the utility itself
still works.

Version 11.2.1 has outgrown the original description. Calling it a menu viewer undersells a tool that also
surfaces machine-wide hotkeys, automation macros and your own link collections through triggers you define.

## What release 11.2.1 puts in front of you

- The complete command listing for the active application, grouped as its own menus group them
- Hotkeys that fire system-wide, presented in the same view rather than in a separate utility
- Macro combinations belonging to Keyboard Maestro, QuicKeys and iKey, shown beside ordinary commands
- Triggers built from modifier keystrokes and mouse clicks, each pointed at a different action
- A collection of addresses you visit often, displayed as a table and opened with one click
- The settings window itself, reachable by trigger for anyone who dislikes menu-bar hunting

## How one working session with it goes

1. **Bring the application forward.** No preparation, no profile selection, no waiting for an index.
2. **Hold your trigger.** The table appears above the window, grouped by menu, with modifier symbols laid out
   exactly as you will need to type them.
3. **Find the command you were about to reach for with the mouse.** It is nearly always there; people are
   simply surprised by how much software ships with.
4. **Release and type it.** The overlay disappears on its own, which is why the utility never occupies
   screen space between requests.
5. **Repeat with a second trigger for your links.** Opening a frequently used address becomes a keystroke
   and a click rather than a detour through a browser window.

## Habits that make the sheet earn its place

Keep the trigger for the table and the trigger for the link collection distinct, so neither feels like a
mode you have to escape from. Trim the shortcut classes down once the novelty passes — a listing you scan in
two seconds beats an exhaustive one you have to read. Keep the link collection short for the same reason.
And when a combination refuses to fire, suspect a collision with something the application already claims
rather than a fault in the utility.
